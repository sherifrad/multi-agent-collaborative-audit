## 🎖️ Competition Rules & Point System
1. **Critical Vulnerability / Hard Blocker (Data Loss, Security, Crash)**: `+50 pts`
2. **Logic & State Machine Bug (Concurrency, State, Lifecycle)**: `+30 pts`
3. **Verified Deterministic Test Case / Regression Proof**: `+25 pts`
4. **Bedside UI/UX & A11y Defect (Ergonomics, Narrow Screen, RTL, WCAG)**: `+20 pts`
5. **Code Pattern & Idiomatic Violation (Architecture / Clean Code)**: `+15 pts`
